# Performance Analysis of OFDM System

## Project Overview

This project analyzes the performance of an OFDM communication system using:

- BPSK
- QPSK
- 16-QAM

under different channel conditions:

- AWGN Channel
- Rayleigh Fading Channel
- Nakagami-m Fading Channel

## Performance Metrics

- Bit Error Rate (BER)
- Signal-to-Noise Ratio (SNR)
- Peak-to-Average Power Ratio (PAPR)

## Software Used

- MATLAB R2024a
- Simulink

## Results

The BER performance of different modulation techniques was evaluated under various wireless channel conditions.
